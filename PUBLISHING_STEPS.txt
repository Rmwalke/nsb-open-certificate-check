Maintainer notes for this companion. The initial public repository is https://github.com/Rmwalke/nsb-open-certificate-check .

1. Use this dedicated public companion repository: Rmwalke/nsb-open-certificate-check.
2. Keep README.md, Code/, audit/ and the notebook at the repository root. Preserve the original license/citation notices.
3. Use a description such as: Data-only exact-rational audit companion for a limited Navier–Stokes preprint; conditional on published enclosure inputs.
4. Suggested accurate topics: navier-stokes, partial-differential-equations, reproducible-research, exact-arithmetic.
5. Use the existing Zenodo DOI for the paper. Do not describe this companion as peer review or full proof verification.
6. For a browser demonstration, submit the public repository URL to mybinder.org and choose Inspect_Certificate.ipynb. Build and verify that launch before distributing it; a local notebook run is not a cloud test.
7. Ask the existing website maintainer to link this repository from the paper's existing page and check that Google Scholar can see the complete abstract and a searchable PDF under 5 MB. Indexing and traffic are not guaranteed.

Only the selected publication payload and this new companion belong in the new repository. The author's existing private research repository and its history are not part of this package.
